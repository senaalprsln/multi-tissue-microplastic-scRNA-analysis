# cross-tissue-microplastic-scRNAseq

**Cross-Tissue Single-Cell Transcriptomic Analysis of Microplastic Exposure in Mouse Kidney, Lung, and Aorta**

**Sena Alparslan**

This repository contains the data-processing pipeline, analysis scripts, and
differential expression results used in a meta-analysis investigating the
effects of nano- and micro-scale polystyrene/polymer plastic exposure on
immune cell populations across three mouse tissues (kidney, lung, and
aorta), using publicly available single-cell RNA sequencing datasets.

## Folder Structure

- `scripts/`
  Contains all Python scripts for quality control, data integration,
  cell-type annotation, and differential expression analysis, numbered in
  the order they should be run.

  - `config.py`: shared marker gene panels, cell-type category
    definitions, and condition-mapping/threshold constants used across
    multiple scripts.

- `processed/`
  Intermediate and final `.h5ad` (AnnData) files generated by running the
  scripts. **This folder is not included in the repository** (see
  `.gitignore`) due to file size; it is created automatically the first
  time the pipeline is run.

- `docs/`
  Contains `methods.md`, a detailed description of the analysis
  methodology, corresponding to the Methods section of the associated
  manuscript.

## Requirements

This pipeline requires Python (3.10) with the following packages:

- `scanpy`
- `anndata`
- `scvi-tools`
- `pandas`
- `numpy`
- `matplotlib`
- `scrublet` (installed automatically as a Scanpy dependency)

Install all dependencies with:

```
pip install -r requirements.txt
```

> **Note:** scVI model training is computationally intensive. A CPU-only
> environment was used for this analysis; training time can be substantial
> without a GPU.

## Scripts and Execution

Scripts must be run in the order listed below, as each script reads the
`.h5ad` output file produced by the previous step.

### 1. Quality Control (per tissue)

```
scripts/01_datasets_qc.py

```
Reads raw 10x Genomics matrices for each tissue, applies tissue-specific
quality-control filtering (detected genes, total UMI counts, mitochondrial
percentage), removes doublets with Scrublet, and saves one QC'd object per
tissue to `processed/{tissue}_qc.h5ad`.

### 2. Merge and Coarse Clustering

```
scripts/02_merge_datasets.py
scripts/03_scvi_integration.py
scripts/04_initial_annotation.py
```
Merges the three QC'd tissue objects into a single dataset, selects highly
variable genes, performs preliminary clustering, and assigns a coarse
cell-type label to each cluster using marker-gene module scoring. This
coarse annotation is used only to define immune vs. non-immune identity for
the batch-covariate construction in the next step, not as the final
cell-type call.

### 3. Selective Batch-Aware Integration

```
scripts/05_scvi_immune_integration.py
```
Trains a single scVI model using a composite batch covariate: immune cells
are labeled by tissue of origin, while non-immune cells are labeled by a
combination of tissue and coarse cell type. This allows immune populations
to be harmonized across tissues while preventing spurious integration of
transcriptionally distinct, tissue-specific non-immune populations.

### 4. Immune Cell Isolation and Annotation

```
scripts/06_immune_clustering.py
scripts/07_immune_annotation.py
```
Filters the dataset to retain only immune-annotated cells, re-clusters this
subset within the integrated latent space, and assigns final immune
cell-type labels using z-score-standardized marker module scores.

### 5. Condition Harmonization and Exploratory Analysis

```
scripts/08_condition_harmonization.py
scripts/09_immune_condition_analysis.py
```
Maps dataset-specific exposure group labels onto a common schema
(*control*, *nano*, *micro*) and summarizes the distribution of immune cell
types across exposure conditions and tissues.

### 6. Differential Expression Analysis

```
scripts/10_immune_DEG.py
scripts/11_immune_subtype_annotation.py
scripts/12_DEG_summary.py
```
Performs Wilcoxon rank-sum differential expression testing (control vs.
each exposure condition) within each tissue/immune-cell-type combination,
resolves finer immune subtypes, and summarizes up- and down-regulated gene
lists for downstream functional enrichment analysis (e.g., g:Profiler).

## Output

Differentially expressed gene lists (up- and down-regulated, per tissue,
cell type, and exposure comparison) are printed to console by
`12_DEG_summary.py` and are intended for use as input to external pathway
enrichment tools. Intermediate annotated AnnData objects are saved at each
stage in `processed/` for inspection or re-use.
